# homebrew-tap

Homebrew tap for hatayama's tools.

## Install uloop

```bash
brew install hatayama/tap/uloop
```

## Formula ownership

`Formula/uloop.rb` is generated by the `update-homebrew-formula` release automation in
[hatayama/unity-cli-loop](https://github.com/hatayama/unity-cli-loop).
Do not edit the formula by hand.
